# Comodín

App web personal (PWA) de organización: horario, tareas de prácticas, gameplan de proyecto, hábitos y sueño.
Funciona sin conexión y sincroniza con Firebase.

- `index.html`: la app.
- `datos.js`: horario, bloques y configuración.
- `sync.js`: sincronización con Firestore.
- `sw.js`: modo sin conexión.
