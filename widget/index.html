📱 Widget del Comodín

Tu horario en la pantalla de inicio o de bloqueo: qué toca ahora, qué viene después y el resto del día. Funciona sin conexión y al tocarlo abre la app.

  1. Instala Scriptable (gratis) desde la App Store.
    Abrir en la App Store
  2. Copia el código:
    ¡Copiado! 
    3. 
      
  3. Abre Scriptable → toca + (arriba a la derecha) → pega el código → toca el título de arriba y llámalo Comodín → Hecho. Si tocas ▶ verás una vista previa.
    4. 
      
  4. En la pantalla de inicio, mantén pulsado un hueco → Editar → Añadir widget → busca Scriptable → elige el tamaño → Añadir widget.
    5. 
      
  5. Mantén pulsado el widget → Editar widget → en Script elige Comodín.
    6. 
    

  


  

    Tamaños

Ahora y siguiente

      
Mediano

Grande

Pantalla de bloqueo
Ahora · siguiente · 🌙

    

    
Opcional: en Editar widget → Parameter escribe entregas o examenes para ver ese modo de semana.

  


  

    El widget se actualiza solo: el código que pegas es un cargador corto que descarga la última versión del widget cada vez, y guarda una copia por si no hay conexión.
    Muestra el horario (clases, prácticas, bloques y eventos fijos). Las tareas y los eventos que crees en la app aparecerán cuando activemos la sincronización.
